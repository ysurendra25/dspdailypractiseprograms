# DSA Daily Practice — Java

A collection of 100+ Data Structures and Algorithms problems solved in Java, maintained as part of daily interview preparation practice.

## Topics Covered

| Topic | Description |
|-------|-------------|
| Arrays | Two-pointer, sliding window, prefix sum |
| Strings | Pattern matching, manipulation, parsing |
| Linked Lists | Singly & doubly linked list operations |
| Stacks | Stack-based problems, monotonic stack |
| Queues | Circular queue, deque, BFS |
| Trees | BST, traversal, level-order |
| Graphs | BFS, DFS, shortest path |
| Dynamic Programming | 1D & 2D DP patterns |
| Recursion | Backtracking, divide & conquer |
| Searching & Sorting | Binary search, merge sort, quick sort |

## Focus Areas

- Time and space complexity optimization
- Clean, readable Java code with proper naming conventions
- Edge case handling
- Pattern recognition across problem types
